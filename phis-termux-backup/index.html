PHIS Termux Backup

A personal utility for creating encrypted PostgreSQL backup archives and storing them in the owner's Google Drive.

Pilot status: backups and deployment remain in a pilot phase. This page does not claim production readiness or unattended operation.

How it works

  1. A database backup is created on the owner-controlled device.
  2. The archive is encrypted on-device with an age public key.
  3. Only the encrypted archive is uploaded to the owner's Google Drive using rclone and Google's OAuth drive.file scope.

The recovery key or private identity is not included with the uploaded ciphertext. Google Drive is the storage provider; this website only documents the utility and does not run backups.

Limited, personal use

This is a single-user, non-commercial experiment. It has no public signup, web login, downloads, or hosted automation. Google authorization takes place on the owner's device, not on this website.
